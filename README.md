# Task Manager — Backend

Серверная часть системы управления задачами в многопользовательской среде: REST API, аутентификация по JWT,
модель компаний/ролей/разрешений, работа с досками и задачами, вложения,
email-уведомления и real-time уведомления через Server-Sent Events (SSE).

## Стек

- **Java 21**, **Spring Boot 4.0.5**
- **Spring Security** (OAuth2 Resource Server, JWT)
- **Spring Data JPA** / Hibernate
- **PostgreSQL**
- **Flyway** — миграции БД
- **Spring Modulith** — модульная организация приложения
- **Resilience4j** — retry/circuit breaker для файлового хранилища
- **Spring Mail** — email-уведомления
- **SpringDoc OpenAPI** — Swagger UI
- **Lombok**

## Архитектура

Проект организован как модульный монолит (Spring Modulith). Каждый бизнес-домен —
отдельный модуль с чётким разделением на публичный контракт и внутреннюю реализацию:

```
com.sergeev.taskmanager
├── company/        # компании, участники, роли, разрешения
├── media/          # хранение и раздача файлов/вложений
├── notification/   # email- и SSE-уведомления, хранение истории
├── security/       # JWT-аутентификация, refresh-токены
├── task/           # доски, колонки, задачи, комментарии, история изменений
└── user/           # пользователи, регистрация, сброс пароля
```

Каждый модуль имеет структуру:

```
<module>/
├── api/            # публичный интерфейс модуля (используется другими модулями)
│   ├── dto/
│   └── event/
└── internal/       # реализация, недоступная напрямую другим модулям
    ├── controller/
    ├── entity/
    ├── mapper/
    ├── repository/
    └── service/
```

Взаимодействие между модулями идёт через:
- публичные `*Api`-интерфейсы (`CheckPermissionApi`, `NotificationApi`, `MediaApi`, ...);
- доменные события (`ApplicationEventPublisher` + `@TransactionalEventListener`).

## Ключевые возможности

- Регистрация/логин, JWT access + refresh токены, сброс пароля по email
- Компании, участники, кастомные роли и разрешения (RBAC)
- Доски, колонки, задачи, комментарии, вложения, история изменений задач
- Real-time уведомления через SSE с персистентностью в БД и настраиваемым TTL
- Фоновые job'ы: очистка истёкших уведомлений, проверка приближающихся/просроченных дедлайнов
- Email-уведомления (сброс пароля, удаление аккаунта)
- Swagger UI для документации API
